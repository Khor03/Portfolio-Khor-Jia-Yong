# Publish this portfolio with GitHub Pages

1. Create a new **public** GitHub repository, for example `portfolio`.
2. Upload the contents of this folder (the `index.html` file and the entire `documents` folder) to the repository root.
3. In GitHub, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/(root)`, and save.
4. After deployment completes, share the site URL:

   `https://YOUR-GITHUB-USERNAME.github.io/portfolio/`

The resume's public link will be:

`https://YOUR-GITHUB-USERNAME.github.io/portfolio/documents/resume.pdf`

All certificate buttons use the same public `documents/` folder and are configured to download when selected.

Keep the repository public so visitors can access the site and PDFs without signing in.
